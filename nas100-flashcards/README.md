# NAS100 交易學習卡

## 快速啟動

```bash
cd nas100-flashcards

# 1. 安裝套件
pip install -r requirements.txt

# 2. 生成資料 (僅第一次需要，約 15 秒)
python3 generate_data.py

# 3. 啟動伺服器
python3 app.py
```

瀏覽器開啟 → http://localhost:5000

## 學習卡規則

- **背景**：顯示過去 60 根 K 棒（5小時）的走勢圖 + 成交量
- **問題**：下一根 K 棒開盤後 **30 分鐘**，你選擇：
  - **BUY（做多）**：預期上漲
  - **SELL（做空）**：預期下跌
  - **HOLD（觀望）**：不確定/橫盤

- **答案判定**（基於 30 分鐘後的收盤價 vs 入場價）：
  - 漲幅 > +0.25% → BUY
  - 跌幅 > -0.25% → SELL
  - 其他 → HOLD

## 快捷鍵

| 鍵 | 動作 |
|----|------|
| `B` | 做多 BUY |
| `S` | 做空 SELL |
| `H` | 觀望 HOLD |
| `N` / `Space` | 下一題 / 跳過 |
