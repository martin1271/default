📊 NAS100 交易規則

最少 2 個訊號確認才入場 · 大納期專用

⏱ 時間框架層次

  • 15分鐘 — 判斷大方向
  • 5分鐘 — 確認方向 + Squeeze
  • 1分鐘 — 精確入場 / 出場
  • 三圖方向一致優先
  • 5/15一致，1分相反 → 唔做

📐 Pattern 型態

  • H Pattern — 尾部確認後入場
  • N Pattern — 尾部突破/回測入場
  • ⚠ 型態未完整 → 唔做
  • ⚠ 唔好過早入場

📉 K線型態（5分鐘）

  • 跌勢中出現 3根上影線
  • 可考慮做空
  • ✗ 1分出現長藍K → 唔空
  • ✗ 15分出現大陽燭 → 唔空

🔵 Squeeze 指標

  • 主要睇 5分鐘 Squeeze
  • 15分鐘作大方向確認
  • 轉勢入場條件：
  • 　Point值 < 50，或
  • 　明顯快將轉向

📊 Bollinger Band

  • 觸及 BOLL 外軌考慮反向
  • 越多時間框架同時觸及
  • → 底部/頭部訊號越強
  • 例：1+5+15分同掂下軌
  • → 強烈做多訊號

🐉 龍珠訊號

  • 1分出龍珠 → 考慮反彈
  • 5分出龍珠（需三圖確認）
  • 　藍珠 → 考慮多（EMA Cloud向上）
  • 　紅珠 → 考慮空（EMA Cloud向下）
  • 15分出7粒龍珠 → 耐心等多

✅ 入場前 Checklist（最少勾選 2 項）

5分 + 15分 方向一致
Squeeze < 50 或轉向確認
BOLL 多圖同時觸及
Pattern 尾部成形確認
龍珠 + EMA Cloud 配合
1分鐘方向一致

🚫 禁止入場情況（Hard Rules）

一日睇唔到清晰勢
5/15分一致，1分反向
5分上影線想空 + 1分長藍
5分上影線想空 + 15分大藍
Pattern 未完整成形
只有 1 個訊號確認
